# CMS للهاتف — مبني بالكامل على الواجهة الأمامية

نظام إدارة محتوى كامل يعمل كموقع ويب من مسارين:
- **`/admin`** — لوحة إدارة مصممة للهاتف (ألوان فاتحة + أزرق سماوي). كل ما يُبنى هنا يُحفظ كمسودة.
- **`/client`** — شاشة العرض النهائي للعميل. تعرض **النسخة المنشورة فقط**، ويتفاعل معها الزائر فعلًا (أزرار، نوافذ، إظهار/إخفاء، أشرطة قابلة للطي، تدفقات، تنقل بين الصفحات).

> بدون باك-إند ولا أي API خارجي — كل شيء (البيانات، الصور المرفوعة، حسابات الدخول، النسخ المنشورة) يُخزَّن **محليًا في `localStorage`** ويعمل حتى بعد إعادة تحميل الصفحة.

## دخول سريع (حساب تجريبي)
المعرف: `admin` — رمز التحقق: `admin123`
(و `editor / editor123` لدور المحرر)

## التقنيات
- TypeScript + React (Vite) + Tailwind CSS v4
- قابلة للنشر على Vercel (ملف `vercel.json` يوجّه كل المسارات إلى `index.html`، SPA)

## أهم ما أُنفّذ
- **شجرة مكوّنات لا نهائية** تُفسَّر من البيانات — لا يُكتب أي كود لكل مكوّن/صفحة جديدة.
- **محرر صفحات/أشرطة/نوافذ/مكوّنات مخصصة** بواجهة تشبه الهاتف: إضافة مكونات، اختيار، لوحة خصائص من الأسفل (محتوى/تصميم/مقاسات/محاذاة/إجراءات/ظهور/متقدم)، شجرة مكوّنات، نسخ/لصق/تكرار/ترتيب/إخفاء/حذف.
- **إجراءات** بحوادث (عند الضغط): انتقال لصفحة، فتح/إغلاق نوافذ، إظهار/إخفاء/تبديل مكوّن، طي/فتح أشرطة، تدفقات، روابط، تراجع/إعادة (سجل داخل المحرر).
- **نشر منفصل عن المسودة**: لوحة نشر تعرض الفروق، نشر الكل/الاسترجاع من سجل النشرات، وتجاهل المسودات. `/client` يقرأ فقط النسخة المنشورة.
- **مكتبة وسائط** برفع صور (data-URL)، **مكتبة مكونات مخصصة**، **تدفقات**، **إعدادات موقع** (الاسم، ألوان الهوية، الصفحة الرئيسية، الحسابات والأدوار)، **مركز إشعارات**.
- **معاينة مباشرة** داخل `/admin` (إطار هاتف) تعرض نفس تجربة `/client` ويمكن التبديل بين «المسودات» و«المنشورة».

## تشغيل محلي
```bash
npm install
npm run dev        # منفذ 5173
npm run build      # إنتاج → مجلد dist
```

ملاحظة: الاعتماد على `localStorage` يعني أن كل المتصفحات في نفس النطاق تشترك في نفس «الموقع». بيانات تجريبية (صفحات، شريط علوي/سفلي، نافذة عرض) جاهزة عند أول فتح، وحساب الدخول `admin/admin123`.

## استرجاع صلاحية الدخول
- في شاشة الدخول: «نسيت رمز التحقق؟» → يُرسَل طلب استعادة → يصل المالك إشعارًا من نوع استعادة يضغط «قبول» فيتولّد رمز تفعيل.
- يرجع صاحب الحساب ويختار «نسيت رمز التحقق» ثم يدخل الحساب + الرمز المستلَم ويُثبّت رمز دخول جديدًا.

## أدوار الحسابات
- **مالك / محرر**: تعديل كامل. **عارض**: وضع القراءة فقط (تُمنع الإضافة/التعديل/الحذف/النشر ويظهر شريط تنبيه).

## نقاط إضافية منقّذة
- **المراجع المكسورة**: شاشة تكشف كل إجراء/وسيط يشير إلى كيان محذوف، مع «الانتقال للمكوّن المصدر» (يفتح المحرر ويحدّد المكوّن) و«حذف المكسور». يُنبَّه عند النشر إن وُجدت.
- **نشر جزئي**: حدّد عناصر بنشرها لوحدها؛ تجاهل المسودات كلها يعيدك لآخر نسخة منشورة.
- **تراجع/إعادة** داخل المحرر (أيقونتان) + حفظ «نشر الآن» للكيان الحالي.
- **حركات ظهور** (تلاشٍ/صعود/هبوط/تكبير)، **ظهور مشروط** بمكوّن آخر، و**إخفاء على الشاشات الصغيرة جدًا**.
- **إجراءات عند الظهور بالتمرير** تُنفَّذ عبر مراقب التقاطع، و**هيكل عظمي** أثناء تحميل /client.
- **أشرطة تقدم على الأزرار**: تلقائي أو عند الضغط، قابلة للإلغاء، تُنفّذ الإجراء عند الاكتمال.
- **إعدادات**: المتغيرات، قواعد إعادة التوجيه والمسارات.
- **عناوين `onOpen`/`onClose`** في النوافذ وطلبات الاستعادة ضمن مركز الإشعارات.
